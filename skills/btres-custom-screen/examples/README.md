# Examples

Finished screens and their sources. Use them as starting points: copy the closest one and adapt it (and say so to the user).

| folder | what it is | units |
|---|---|---|
| [`hello-boost/`](hello-boost/) | the smallest useful screen: a boost readout and a bar from `psrg_w` / `pu_w`. `screen.html` + `screen.js`, package with `make_screen.py`. Start here for a new screen. | any (re-lay out per unit) |
| [`pull-lab/`](pull-lab/) | Pull Lab: pull detection with a PASS / CAUTION / FAIL verdict, boost / lambda / LPFP graphs, per-cylinder knock, last 5 pulls. Finished JSON. | S-series 1920x480 only |
| [`live-dyno/`](live-dyno/) | Live Dyno: estimated whp / torque curve from a pull, comparison against earlier pulls. Finished JSON. | S-series 1920x480 only |
| [`knock-screens/`](knock-screens/) | 3D-engine screens with per-cylinder knock and ignition callouts for a V8 (6/7/8 series) and a 5-cylinder (RS3 / TT RS), with the build scripts. Shows WebGL, firing-order mapping, loading state, off-screen handling. | S-series and M1 / X1 |

Pull Lab and Live Dyno are ready-made `.json` files, not generated by the scripts here. Their patterns are described in `../reference/patterns.md`.
